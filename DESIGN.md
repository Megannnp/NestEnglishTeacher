# Design Notes

## Direction

This site is an index library for Chinese English teachers. It should feel like a maintained desk reference, not a marketing landing page.

## Principles

- Resource pages use left-side filtering and right-side scannable rows.
- Resource results behave like a search engine: query state, ranking, editor rating, tags, and a short site-owner note.
- Tutorials are original content and should read more like a knowledge base than a blog.
- International resources live inside resource filters, not as a separate site section.
- The site never implies that third-party files are hosted or downloadable here.

## Visual System

- Main surface: quiet off-white background with white content panels.
- Accent: deep green for active filters, links, and primary actions.
- Shape: small to medium radius, no oversized rounded cards.
- Density: compact enough for browsing many links, with enough line height for Chinese text.
- Motion: subtle hover feedback only.
- Ratings are editorial signals, not user-generated review data.
